# 短令牌账号与同步

Python 3 标准库及 SQLite，无需在服务器安装 Node.js。运行：

```sh
LP_DATA_DIR=/private/tmp/lingua-prism-data python3 server/app.py
```

Vite 开发代理把同源 `/api` 转发到本机 8787。生产环境必须通过同源 Nginx 代理；不要把接口端口暴露到公网，也不要把数据库放进网页目录。GitHub Pages 没有后端，保持访客模式。

首次部署以管理员身份运行 `deploy/api/install.sh`，然后把 `deploy/api/nginx-location.conf` 放入现有站点的 `server` 块，检查配置后重载 Nginx。安装脚本不会自行修改宝塔站点。后续 Actions 部署接口代码到独立版本目录，健康检查失败时回退。前后端数据格式变更需保持兼容；回退代码不会回退用户数据库。

短令牌由用户输入，8–32 位英文、数字、下划线或连字符，区分大小写；首次使用创建账号。相同令牌登录同一账号，不绑定手机号或邮箱。没有找回机制，昵称不是验证因素。令牌只在登录请求中使用，不保存到浏览器；服务器保存带密钥的 HMAC。会话 Cookie 为 HttpOnly、SameSite=Strict，有效期 30 天，HTTPS 下自动使用 Secure。当前 HTTP 部署可用，但不能提供传输保密性。

同步内容：昵称、头像、已完成的 TALL 单项成绩及答题记录、问卷答案和所在步骤、已有语言、版本选择与权重。计时中的单项测验不跨设备续答，退出仍作废。访客数据保留在本地，登录时可自行选择是否导入。不同设备修改不同字段时合并；同字段冲突时当前同步设备优先；同一项已完成测验以完成时间较新的完整记录为准。设备时钟差异会影响这一选择。断网期间保留本地修改，恢复连接后重试。

数据库和密钥存放于 `/var/lib/lingua-prism`，由独立 `lingua-api` 系统用户持有，目录权限 700，文件 600。数据库与密钥须一起备份；密钥丢失会导致原令牌无法匹配。可暂停服务复制整个目录，或使用 SQLite backup API 获取一致快照后另行复制密钥。备份不要放在网站目录或 Git 仓库；删除账号会删除在线数据并终止其所有会话，已有离线设备缓存与管理员备份需分别清理。

测试：`npm run test:server`。覆盖同令牌登录、账号隔离、版本冲突、持久化写入、注销、删除、来源检查、格式校验、登录限流与文件权限。
