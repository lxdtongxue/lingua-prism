| `src/sections/` | 页面各段：首屏、测试中心、语言推荐、框架、五维、能力、目标、参考文献、页脚 |

| `test/index.html`、`src/test.tsx` | 做题页入口，和首页分开构建 |
| `src/components/languages.ts` | 用户选择的 L1、L2 |

| `src/gl/engine.ts` | 渲染引擎：滚动同步、指针、弹簧动画、自适应画质 |
| `src/gl/shaders.ts` | 全部 GLSL：场景、模糊、镜面地面、玻璃 |
| `public/fonts/` | 未修改的 HarmonyOS Sans 字体和许可文本 |

## v2 的结构

- **手机和小平板（宽度 900 及以下）：** 每个 Tab 是一个左右翻页的页面，内容在页面内上下滚动。分组写在 `src/components/pager.ts` 的 `GROUPS`，和 `App.tsx` 里的 `.tabpage` 对应，翻页时背景由引擎按页偏移。
- **两级内容：** 外层用 `Card` 放简短摘要，点开 `Sheet` 看详情。`Sheet` 打开时页面淡出，它是直接落在画布上的真玻璃。
- **导航：** Tab 固定在底部，下滑收成当前页的圆形图标。标题随下滑移到中间，语言切换同时消失。
- **进站动画：** `src/components/Intro.tsx`，每个会话播放一次。网址加 `?intro` 可强制重播。

## 新增内容

- 改文字或数据：只动 `content.ts`，中英文要同时改。
- 换测验题目：只动 `public/tall/`，步骤见 `src/tall/README.md`。
- 新增一块玻璃：`<Glass radius={30} {...CLEAR}>…</Glass>`，`CLEAR` 是 `Card.tsx` 里的通透预设，文字多的面板可调高 `frost` 和 `dim`。
- 新增一项可点开的内容：`<Card … onOpen={…} />` 配 `<Sheet open={…} onClose={…} title="…">…</Sheet>`。
- 悬浮在 DOM 内容之上的元素（导航）用 CSS 类 `.chrome`。WebGL 看不到 DOM，所以这类元素不能用 `Glass`。
- 带自有动画的玻璃（比如滑块）要自己写 `transform`，并传 `reveal={false}`。
- 需要液态选中效果的标签组用 `useLens`（见 `src/components/useLens.ts`），滑块会自动跟随布局变化。滑块的 `Glass` 要传 `layer={1}`，否则会被父面板盖住。

## 两种玻璃

| | `Glass`（WebGL） | `.chrome`（CSS） |
| --- | --- | --- |
| 用在 | 页面内容里的面板和按钮 | 浮在内容上方的导航、语言切换 |
| 折射内容 | 背景场景，看不到 DOM 文字 | 浏览器合成的全部内容 |
| 效果 | 折射、色散、反射、涟漪 | 模糊和高光 |

## 关于字体许可

HarmonyOS Sans 免费，但有条件：

- 不能修改字体文件，所以**不能做子集化或转 WOFF2**。
- 必须在软件里显著声明使用了该字体，页脚已包含。
- 必须保留版权声明和许可文本，见 `public/fonts/LICENSE.txt`。
- 不能单独分发或出售字体。

部署时给 `.ttf` 开启服务器的 gzip 或 brotli 传输压缩。这只压缩传输过程，不改动文件。

## 开发调试

- 做题页是单独的入口（`test/index.html`、`src/test.tsx`），不加载 WebGL 引擎，避免渲染影响计时。
- 引擎是带 WebGL 上下文的单例，所以 `src/gl/` 的改动会触发整页刷新，这是 `vite.config.ts` 特意设置的。
- 开发模式下控制台有 `__engine`：`__engine.bench()` 直接测各画质档的 GPU 耗时，`__engine.settle()` 立即完成所有入场动画。
- 后台或隐藏的标签页会节流 `requestAnimationFrame`，这时看到的帧率不代表真实性能。
